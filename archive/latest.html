Claude Code will now act on its own by default
Simon Willison
Starting August 14, "Auto mode" — a setting that lets Claude Code (Anthropic's AI coding assistant, which can write, edit, and run code inside your project) decide how much to plan before taking action — becomes the default for people on Pro, Max, and Team subscription plans. Previously, users had to turn this on themselves. Anthropic says it's confident enough in the system's judgment to flip the default rather than keep it opt-in, though the tool can still pause and ask permission for riskier actions.
Why it matters
Developers using Claude Code will now hand more day-to-day judgment calls to the AI by default, raising the stakes if it misjudges a task or introduces a bug before a human notices.

A safe box to let AI agents run code without wrecking your computer
Hacker News · 250 pts
Docker released Docker Sandboxes, a way to give AI agents their own disposable, walled-off environment to run commands, edit files, or execute code in. Because the sandbox gets thrown away after use, anything the AI does inside it — including mistakes — can't spill out and damage the real system. The tool drew 250 upvotes on Hacker News, a strong signal of developer interest.
Why it matters
As AI agents get more freedom to act on their own, tools that contain the damage from their mistakes are becoming essential infrastructure, not a nice-to-have.
Published as: “Docker Sandboxes – Disposable, isolated sandboxes for AI agents”

Scientists are getting closer to reading short bits of speech from brain scans
HF Daily Papers · 67 pts
Researchers used MEG — magnetoencephalography, a non-invasive scanner that measures tiny magnetic fields produced by brain activity — combined with an AI system to retrieve short segments of speech a person had merely heard, based only on their brain signals. The AI system works well, but its internal workings don't map cleanly onto known brain science, so the researchers studied exactly which features of speech, like pitch or rhythm, it actually relies on.
Why it matters
This is early-stage lab research, not a mind-reading device coming soon, but it's part of a growing body of work with implications for future devices that could help people who can't speak communicate.
Published as: “Interpretable MEG Decoding of Perceived Speech: Cortical Sources and the Stimulus Features That Drive Retrieval”

Words used in this issue
Plain-English definitions for the technical terms above.
Parameters
The internal settings a model learns during training; more parameters generally means more capability but also more computing power needed to run it.
MCP connector
A standard way for an AI model to plug into outside apps and services so it can pull in real data instead of guessing.
Sandbox
A disposable, walled-off digital environment where software (including an AI agent) can run without being able to affect the real system outside it.
Open weights
A model whose underlying files are released publicly so anyone can download, modify, and run it on their own computer instead of renting access from a company.
Multimodal
An AI system that can handle more than one type of input, such as both text and images, instead of just one.
MEG (magnetoencephalography)
A scanning technique that measures tiny magnetic fields produced by brain activity without any surgery or implants.
